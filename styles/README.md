# Styles

A style is a direction, not a recipe: the principles behind a look, a motion vocabulary, a way to structure
a film, a sound and the effects it leans on. Pick one (or two) in the brief before writing scenes — it turns
a vague ask into concrete decisions. Then make it yours: the numbers and timelines in each file are examples
from real films, starting points to bend for the story, the brand and the length. Mix styles freely when the
story has parts (a kinetic hook into a product showcase); what matters is that each choice is deliberate.

Styles are shared by every skill in this plugin (motion now, music later): a style also says how it sounds.

| style | use when | feels |
|---|---|---|
| [kinetic-type](kinetic-type.md) | a message, a manifesto, a launch line, no product visuals | loud, punchy, poster-like |
| [product-showcase](product-showcase.md) | showing range: features, templates, screens, "what X can do" | rich, spatial, impressive |
| [character-story](character-story.md) | a mascot, a brand character, a story with a hero | warm, playful, narrative |
| [editorial](editorial.md) | premium, calm, thoughtful; quotes, numbers, brand values | composed, confident |

The studio rules (`skills/motion-engineer/references/rules.md`) apply to every style. Techniques shared by all
styles live in `skills/motion-engineer/references/craft.md`.

## Writing a new style
Copy the sections below. Explain the *why* behind each choice, then give concrete example numbers — hex roles,
easings, durations, a sample timeline — so the next film has a place to start without being locked in.
Mark a style as untested until one film has been made with it and its contact sheet passed the loop.

```
# <name>
One line: what it is and when to pick it.
## Look         palette roles, type (faces, sizes, case), layout habits, what is banned in this style
## Motion       vocabulary with easings/durations; camera; what never happens
## Structure    one way to do it: a sample timeline, the hook, the ending/loop
## Sound        groove and accents
## Effects      library effects this style leans on
## Pitfalls     what the contact sheet usually catches in this style
## Reference    a film made in this style: brief + scene table
```
